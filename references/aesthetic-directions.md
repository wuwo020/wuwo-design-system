# 三套审美方向（v2 · 一个项目只选一套）

> v1 的问题：只有一套「暗夜梦核」token + 54 个外站风格随便挑，AI 每次拼一点，结果是「哪都像、哪都不是」。
> v2 规则：**动手前用一句话声明方向**（例：「这是沉浸暗场方向，团播活动页，主角是主播影像」），之后所有颜色、字体、动效都从这套方向推导。**不混搭**。54 个外站模板只用来借「原则」，不用来换皮（见 `library-guide.md` §风格库）。

| 方向 | 一句话 | 典型场景 | 动效性格 |
|---|---|---|---|
| **A 沉浸暗场**（默认） | 黑场里只亮主角：影像、超大字、一个点缀色 | 团播/主播介绍、活动页、品牌故事、人物志、作品集 | 电影感：跟手 scrub、pin 叙事、慢进快出 |
| **B 仪器极简** | 单色、结构即装饰、数据本身就是画面 | 后台、工具、AI 秒聘管理端、数据看板、设置页 | 机械感：短、准、无回弹，像按键「咔哒」 |
| **C 暖调编辑** | 纸面阅读感，排版做主角 | 长文、报告、公司介绍、招聘详情、对外文档 | 克制：阅读优先，只在图片揭示/进度上跟手 |

**选择依据是「谁在什么环境看」，不是「这个行业一般用什么」**：深夜刷手机看直播相关内容 → A；白天办公处理数据 → B；认真读一篇东西 → C。

## A · 沉浸暗场（Immersive Dark）——默认

继承机主历史作品（人物志、故事、梦境记录）的「夜里、影像、情绪」气质，但 **v2.1 起重做了暗色**。

### 为什么 v1 的暗色显得 low（机主 2026-09-25 反馈：「没有设计感、很 low、没有质感」）
- **底色是 SaaS 深色模式的藏青**（`#0B1020`）：这是后台/开发者工具的默认暗色，一看就是「程序员的夜间模式」，不是「影像的夜」。
- **文字是冷蓝白 + 蓝灰**，次要文字换成另一种颜色（`#93A0C2`），同一页出现三种色温，发散、不统一。
- **点缀是糖果粉/薄荷/薰衣草**：高明度低饱和的「马卡龙」色，在暗底上发光发飘，像 App 模板。
- **没有材质**：一整块平涂的纯色，没有光、没有颗粒、没有暗角，扁平单薄。
- **影像位是线框占位**：圆角灰框居中写字，像原型图，打断沉浸感。

### 质感从哪来（四条，缺一条都会变回 low）
1. **调色**：底色用**带温度的近黑**（暖墨/石墨/深岩），不用藏青、不用纯 `#000`；三阶底色只差亮度不差色相。
2. **文字同色温**：主文字是**骨白**（微暖的灰白），次要/元信息用**同一个颜色降透明度**（.74 / .56），不换色——暗底上层级靠透明度阶梯，色温才统一。
3. **材质与光**：全页一层**胶片颗粒**（SVG 噪点，opacity .06，overlay 混合），首屏一束**顶光**（极淡的暖色径向）+ **暗角**。光是照在内容上的，不是飘着的光球。
4. **克制的点缀**：全页**一个**点缀色，**偏沉、偏低明度**（香槟/胭脂/青瓷），只落在：一个圆点、一条线、一组编号、按钮悬停；另设一个**「直播中」状态色**只给 REC/LIVE 点用。**正文里不许高亮词**（那是电商详情页手法）。

### Token（三套调色板，一个项目选一套；结构相同，换值即可）

```css
/* 默认：石墨 · 香槟 —— 最稳，适合品牌/活动/公司对外 */
:root {
  --bg:   #0C0C0D;  --bg-2: #141415;  --bg-3: #1C1C1E;   /* 三阶：页面 / 分区 / 抬升面 */
  --fg:   #EDEAE4;                                       /* 骨白 */
  --fg-2: rgba(237,234,228,.74);                         /* 正文/导语，暗底上低于 .7 读不清 */
  --fg-3: rgba(237,234,228,.56);                         /* 元信息/编号 */
  --rule: rgba(237,234,228,.11);                         /* 1px 分隔线 */
  --accent: #C9A96E;                                     /* 香槟 */
  --live:   #D0574A;                                     /* 胭脂：只给直播状态点 */
  --light:  rgba(255,236,205,.055);                      /* 顶光 */
}
/* 墨 · 胭脂 —— 更情绪，适合主播个人志/人物故事 */
[data-palette="rouge"] {
  --bg:#0F0E0D; --bg-2:#161412; --bg-3:#1E1B18;
  --fg:#EEE8DE; --fg-2:rgba(238,232,222,.74); --fg-3:rgba(238,232,222,.52);
  --rule:rgba(238,232,222,.11); --accent:#A8544A; --live:#D8584A; --light:rgba(255,210,175,.06);
}
/* 深岩 · 青瓷 —— 冷调、疏离，适合纪录/复盘/数据叙事 */
[data-palette="celadon"] {
  --bg:#0B0F12; --bg-2:#11171B; --bg-3:#182127;
  --fg:#E5EAEC; --fg-2:rgba(229,234,236,.74); --fg-3:rgba(229,234,236,.52);
  --rule:rgba(229,234,236,.11); --accent:#93BBAA; --live:#D0574A; --light:rgba(195,228,232,.05);
}
```

颗粒层（直接抄，放 `body::after`，`position:fixed; pointer-events:none; opacity:.06; mix-blend-mode:overlay`）用 SVG `feTurbulence baseFrequency=.85` 的 data URI，完整代码见 `templates/story-scroll/index.html`。

### 字体
- 标题：**中文衬线 Heavy/Black**（Noto Serif CJK SC 900 / 思源宋体 Heavy），行高 1.1，字距 -0.015em。暗底会吃掉宋体细横笔——**必须用 900 字重**，可再补 `-webkit-text-stroke:.012em currentColor`。
- 正文：黑体 400（暗底别用 300，会发虚），17px / 1.85。
- 元信息/时间码：等宽字体，数字 `tabular-nums`；**加宽字距只给英文和数字**，中文不拉字距（拉开很刻意）。

### 构图规则
- **每屏一个主角**：一张影像 / 一句超大标题 / 一个跟手动画时刻，三选一；其它元素退后。
- **尺度反差要狠**：标题 `clamp(40px, 11.5vw, 104px)`，正文 17–18px，元信息 11–12px。中间尺寸越少越高级。
- **影像位像一帧胶片，不像线框**：深色实底 + 1px 极淡描边 + 取景角标 + 时间码/REC 点；有真实素材就出血铺满（`object-fit: cover`）并加底部压暗。**不画假插画、不堆光晕球、不在框里居中写说明文字**。
- **深度 = 影像 + 顶光/暗角 + 前后景速度差**（视差）+ 下沉阴影 `0 40px 80px -40px rgba(0,0,0,.8)`，不是发光。
- 分区用大留白（96–160px）和底色 `--bg → --bg-2` 切换，**不用卡片网格承载整页结构**。
- 圆角 2 档：媒体 4px（暗场里锐一点更贵），控件 999px 胶囊。
- 主按钮 = **骨白实心胶囊、黑字**（暗底上最「贵」的按钮是反白），悬停换点缀色；不用描边发光按钮。

### 允许 / 禁止
- ✅ 点缀色只用在：一个圆点、一条进度线、一组时间编号、按钮悬停。
- ✅ 文字压在影像上时，用底部压暗遮罩（`linear-gradient(to top, var(--bg) 10%, transparent)`）保证可读。
- ❌ 藏青/蓝黑底（SaaS 深色模式感）、纯 `#000` 平涂底（B 方向专用）。
- ❌ 马卡龙点缀（糖果粉/薄荷/薰衣草）、两个以上点缀色同屏、正文里高亮词。
- ❌ 渐变字、霓虹描边、卡片外发光、满屏粒子背景、玻璃卡片当默认容器、蓝紫靛渐变。
- ❌ 次要文字换成另一种颜色（必须同色降透明度）。

## B · 仪器极简（Instrument）

吸收自 Nothing 设计体系（MIT）的「减法」立场，适配中文。**后台和工具默认选它**，不要给后台套 A 的电影感。

### Token

```css
:root {                       /* 暗色（OLED 黑） */
  --bg: #000; --surface: #0E0E0E; --line: #222;
  --t1: rgba(255,255,255,1);  /* 仅 1 处：本屏最重要的数字/状态 */
  --t2: rgba(255,255,255,.9); /* 正文 */
  --t3: rgba(255,255,255,.6); /* 标签/说明 */
  --t4: rgba(255,255,255,.4); /* 时间戳/禁用 */
  --interrupt: #D71921;       /* 红=打断，「现在看这里」，没有紧急事就不出现 */
  --ok: #4CAF7A; --warn: #E0A030;  /* 只涂在数值本身，不涂整行背景 */
}
[data-theme="light"] { --bg:#F5F4F0; --surface:#FFF; --line:#E2E0DA;
  --t1:#000; --t2:rgba(0,0,0,.88); --t3:rgba(0,0,0,.6); --t4:rgba(0,0,0,.4); }
```
亮暗两套都是一等公民，按使用环境选（白天办公→亮，值班/夜间→暗）。

### 规则（Nothing 三层法则，中文化）
- **每屏恰好三层**：主（一个数字/标题/状态，巨大）→ 次（紧贴主的说明，8–16px 间距）→ 末（元信息，最小最淡，推到边缘）。眯眼看，第一眼只能落在一处。
- **字体预算**：每屏最多 2 个字族、3 个字号、2 个字重。想加字号前先试「加间距」。
- **容器阶梯**（能用上面的就不用下面的）：纯间距 → 一条分隔线 → 细描边 → 抬升面。最重要的元素永远不装盒子。
- **每屏只破格一处**：一个超大数字 / 一个圆形控件 / 一个红点。零处=死板，两处以上=混乱。
- **数据就是画面**：`98.2%` 用等宽数字 48px 本身就是视觉，不需要插图、环形图装饰。
- 数字一律 `font-variant-numeric: tabular-nums`。
- 字体：拉丁 `Space Grotesk` + `Space Mono`（标签），中文 `Noto Sans SC`；等宽只用于数据/代码/标签，**不当「科技感」戏服**。

### 允许 / 禁止
- ✅ 分段进度条、刻度、表格、状态点。
- ❌ 图标+标题+一句话的等宽卡片网格（后台最常见的 AI 味）、渐变、玻璃、阴影堆叠、emoji 当图标。

## C · 暖调编辑（Warm Editorial）

长阅读的纸面感。**注意**：「奶油底+琥珀+深墨」也是 AI 做「高端消费品」时的默认色板（taste-skill 列为禁用默认）。所以 C 只用于**阅读型页面**，不用于卖货页；卖货/品牌页回到 A 或按品牌定制。

### Token

```css
:root {
  --paper: #F7F4EF; --paper-2: #EFEAE2; --ink: #1A1A1A;
  --muted: #6E635B; --rule: #D9D1C5;
  --accent: #B5562F;   /* 陶土红：只用于链接下划线、引文竖线之外的强调词 */
}
```

### 规则
- **排版是主角**：标题衬线（`Noto Serif SC` 700–900 或 霞鹜文楷），正文无衬线 17–19px / 行高 1.8。
- **行长**：中文每行 28–38 字（`max-width: 36em` 左右），英文 65–75ch。PC 上宁可两侧留白，也不要一行 60 个汉字。
- 引文用大号衬线 + 缩进，不用左侧彩色竖条（side-stripe 是 AI 味）。
- 图片可以出血全宽，图注小字左对齐。
- 动效只做三件事：阅读进度条、图片滚动揭示（`clip-path` scrub）、目录高亮。**不做花哨入场**。

## 方向 × 双端的对应（详细规则见 `responsive-dual.md`）

| | 手机网页 | PC 网页 |
|---|---|---|
| A 沉浸暗场 | 全屏竖向叙事，拇指滑动 scrub；横向画廊变左右滑卡 | 同一叙事改成左右分栏 + pin；横向画廊用滚轮驱动横移 |
| B 仪器极简 | 单列，主数字置顶，操作固定在拇指区（底部） | 多列密排，侧边导航，键盘快捷键 |
| C 暖调编辑 | 单列正文，图片全宽 | 正文居中窄栏 + 边栏目录（sticky），宽图可突破栏宽 |
