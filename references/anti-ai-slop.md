# 去 AI 味（v2 · 视觉 + 文案 + 动效）

> 机主明确要求保留并加强这一块。「AI 味」= 读者一眼看出「这页是 AI 生成的」，它分成三层：
> **视觉层**（配色/容器/构图套路）、**文案层**（正确的废话、对仗排比、「赋能」）、**动效层**（万物淡入）。
> 来源：impeccable `craft-floor`（质量底线）、`taste-skill`（审美立场）、`uizze/anti-ui-slop`（AI 味清单）、Nothing 设计体系（减法），均为 MIT/公开许可，本文件是中文提炼 + 本机增补。

## 1. 视觉层：硬禁清单（看到就改）

| 禁止 | 为什么是 AI 味 | 换成 |
|---|---|---|
| 渐变文字（`background-clip: text`） | 2024 年后最典型的「AI 感标题」 | 纯色 + 更大字号；要强调就加粗/换色，不改填充 |
| 玻璃拟态当默认容器（`backdrop-filter`） | 廉价的「现代感」贴片 | 实色抬升面 + 1px 描边；实在要模糊只用在**浮层**（弹窗/底部栏） |
| 紫→蓝→靛三色渐变 / `#6366F1` 系 | AI 生成图的默认配色 | 用方向 token 里的点缀色，全部只选 1 个 |
| 「图标 + 标题 + 两行说明」等宽卡片阵列（3 或 4 张） | AI 落地页的默认骨架 | 改成不对称布局、表格、或一句话 + 一图；数量不为凑数而设 |
| 左侧彩色竖条（`border-left: 4px`）当装饰 | 也被列为最典型的 AI 记号 | 用引号、缩进、或分隔线，不用彩色条 |
| 首屏居中的「标题 + 副标题 + 两个按钮」万能模板 | 没有观点 | 先决定主角是谁：影像、数字、还是标题 |
| 假插画、假数据、假头像（`placeholder.com`、灰底人像） | 一眼假 | 真实照片/真实数据；没有就不放，用排版撑住 |
| emoji 当图标（🚀✨🎯） | AI 文档/网页的习惯 | 线性图标（Lucide/Phosphor）或纯文字标签 |
| 每张卡都大圆角 + 大阴影 + 悬浮上移 | 「AI 组件库默认值」 | 容器阶梯：间距→分隔线→描边→抬升面，能省就省 |
| 满屏粒子/星空/网格背景 + 呼吸发光球 | 廉价「科技感」 | 留白、真实影像、或一个克制的几何图形 |
| `#F7F4EF` 奶油 + 琥珀 + 深墨 | 另一个 AI 默认色板（「高端消费品」） | 仅阅读型页面可用，卖货/品牌页按品牌定制 |
| 大量英文大写 letter-spacing 小标题（EYEBROW / FEATURES） | 英文模板残留 | 中文语境用中文小标题，需要标签就用小字+中间点 |

**替代思路（比清单更重要）**：AI 味来自「默认值堆叠」，去味靠**取舍**——
1. 每屏只留一个视觉主角，其余元素主动降级。
2. 颜色数量：底 + 文字 2 阶 + 点缀 1 个，够了。
3. 装饰元素问一句「删掉会怎样」，答不上来就删。

## 2. 文案层（中文特有，最容易被忽略）

AI 中文的空洞特征：**正确、通顺、无信息**。删掉这些：

- **正确的废话**：「在当今数字化时代」「随着科技的不断发展」「为用户提供更好的体验」→ 直接说事。
- **对仗排比**：「更高效、更智能、更便捷」「赋能行业、赋能伙伴、赋能未来」→ 说一件具体的事。
- **热词堆砌**：赋能、闭环、抓手、生态、一站式解决方案、数字化转型、全新升级 → 全部删掉或替换为动作。
- **万能后缀**：「致力于」「专注于」「旨在」→ 主语直接做动作。
- **无主体的承诺**：「打造极致体验」→ 谁体验？体验到什么程度？说不清就删。
- **假数据**：「服务超过 1000+ 客户」——没有真实数字就不要写数字；有就写准确数字。
- **每条都配一句金句**：不是每条都需要升华。让事实自己说话。
- **标题加 emoji 或「✨」**：删。

具体要求：
- 每个标题必须**具体**（「三分钟出一个选题」优于「高效创作」）。
- 一句话里最多一个形容词；能用名词+动词说清就不加修饰。
- 公司/主播相关内容一律用**真实名字、真实时间、真实数字**（团播业务里这些都有）。
- 文案写完念一遍：像不像人说的话？像 PPT 就重写。

## 3. 动效层

- ❌ 万物淡入上移（`opacity 0→1; translateY(20px)`）——AI 生成页面的招牌动作。选 1–2 个真正的跟手时刻（见 `scroll-gesture-motion.md`），其余元素直接静态出现。
- ❌ 每一屏都入场动画；同一页超过 3 处入场动画就过了。
- ❌ 用「动画」掩盖信息缺失（转圈、骨架屏永远转）——先把内容做出来。
- ❌ 全局 smooth scroll + 惯性过强（`duration > 1.2s`）——像在泥里划船。
- ✅ 只在一个地方做「惊喜」：一个 scrub 叙事或一个手势交互，做透。

## 4. 交付前自检（逐条回答，不能跳过）

1. 这页的**审美方向**是哪一套？我能在截图里指出它的三个特征吗？
2. 把所有装饰性渐变/玻璃/阴影关掉，页面还成立吗？（不成立=靠贴片撑，重做）
3. 首屏第一眼落在谁身上？说不出具体元素就是没主角。
4. 文案里有没有「赋能/闭环/一站式/极致/全新升级」？有没有假数字？
5. 手机截图和 PC 截图并排，PC 是不是「放大的手机页」？
6. 关掉 JS、开启 reduced-motion，内容是否完整可读？
7. 换成竞品的内容，这页还认得出是我们做的吗？（认不出=没有个性）
